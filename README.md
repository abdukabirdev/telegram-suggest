# Telegram Suggest

Персональные автоподсказки слов при наборе в **Telegram Desktop** (Windows 10/11),
по принципу клавиатуры смартфона: программа учится на вашем наборе и после 1–2 букв
предлагает 3–5 самых вероятных слов.

- Работает только когда активно окно `Telegram.exe`. В остальных программах полностью пассивна.
- Языки: узбекский (кириллица и латиница), русский, английский.
- Все данные хранятся только локально (SQLite). Никакой сети и телеметрии.
- В базу попадают только отдельные слова и пары слов, набранный текст целиком не сохраняется и не логируется.

## Управление

| Клавиша | Действие |
|---|---|
| `Tab` | принять первую подсказку |
| `Ctrl+1/2/3` | принять вариант 1/2/3 |
| `Esc` | скрыть подсказки |
| `Ctrl+Alt+P` | пауза / возобновление |

## Разработка

Требуется Python 3.11+ (проект разрабатывается на 3.14) и Windows 10/11.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest
```

## Структура

```
app/
  main.py          точка входа
  hook.py          низкоуровневый хук клавиатуры (WH_KEYBOARD_LL) в отдельном потоке
  keymap.py        клавиша -> символ с учётом раскладки (ToUnicodeEx)
  window_watch.py  определение активного окна Telegram
  engine.py        буфер слова: поток символов -> подсказки и обучение
  lexicon.py       словарь в памяти: поиск по префиксу, ранжирование, биграммы
  textutil.py      границы слов, правила «что запоминать», токенизация
  translit.py      транслитерация узбекского кириллица <-> латиница
  store.py         SQLite: слова, биграммы, настройки
  overlay.py       окно подсказок (не забирает фокус)
  positioning.py   стратегии определения позиции окна подсказок
  inserter.py      вставка слова через SendInput
  importer.py      обучение на экспорте Telegram (result.json)
  tray.py          значок в трее
  settings.py      настройки и окно настроек
scripts/
  try_core.py      консольная проверка ядра без Telegram (база в памяти)
tests/             pytest
```

## Как работает ранжирование

- У каждого слова есть счётчик использований, который затухает со временем
  (по умолчанию вдвое за 30 дней). Недавние слова оказываются выше старых.
- Если слово часто идёт после предыдущего (биграмма), оно получает прибавку:
  после «Салом» первым будет «алейкум».
- Ў/у, Қ/к, Ғ/г, Ҳ/х при поиске считаются одной буквой: «кил» найдёт «қилдим».
- Регистр: имя, написанное с заглавной в середине фразы, запоминается с заглавной.
  Заглавная в начале предложения ничего не доказывает и не учитывается.
- Не запоминаются: числа, ссылки, почта, @имена, #теги, слова короче 2 букв
  и слова из одной повторяющейся буквы.

### Выбор подсказки: клавиатура и мышь

- Клавиши: `Tab` (первая), `Ctrl+1/2/3`, `Esc` (скрыть).
- Мышь: клик по любому варианту в окне подсказок вставляет это слово.
  Окно не забирает фокус (`WS_EX_NOACTIVATE`), поэтому курсор в Telegram остаётся на месте.
  Клик по самому окну подсказок не считается кликом мыши «в поле ввода» и не сбрасывает буфер слова;
  клик в любом другом месте сбрасывает буфер, как обычно.
- Под курсором вариант подсвечивается, чтобы было понятно, что он нажимаемый.

### Требования к простоте для обычных пользователей

Программа рассчитана на людей, которые не разбираются в компьютерах:

- Запуск двойным щелчком по одному `.exe`, без установки Python и прав администратора.
- Никакой консоли и редактирования файлов: всё управление через значок в трее и окна настроек.
- Весь интерфейс и все сообщения на русском, понятным языком (без слов «хук», «буфер», «процесс»).
- При первом запуске короткое приветствие: что делает программа, какие клавиши, где значок в трее,
  и вопрос про автозапуск с Windows.
- Разумные настройки по умолчанию: работает сразу, ничего настраивать не нужно.
- Понятные сообщения об ошибках с подсказкой, что делать; программа не падает молча.
- Подсказка для окна SmartScreen/антивируса: почему может появиться предупреждение и как его пропустить.
