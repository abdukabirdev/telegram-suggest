# Telegram Suggest

Персональные автоподсказки слов при наборе в **Telegram Desktop** (Windows 10/11),
по принципу клавиатуры смартфона: программа учится на вашем наборе и после 1–2 букв
предлагает самые вероятные слова.

- Работает только когда активно окно `Telegram.exe`. В остальных программах полностью пассивна.
- Языки: узбекский (кириллица и латиница), русский, английский.
- Все данные хранятся только на этом компьютере. Никакой сети и телеметрии.
- В базу попадают только отдельные слова и пары слов, набранный текст целиком не сохраняется и не логируется.

## Как пользоваться

| Действие | Как |
|---|---|
| вставить первую (выделенную) подсказку | `Tab` |
| вставить вариант 1/2/3/4 | `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+4` (номера видны на словах, пока зажат `Ctrl`) |
| вставить любую подсказку | щелчок мышью по слову |
| удалить слово из словаря | правый щелчок по слову → ещё раз щёлкнуть по «Удалить …?» |
| скрыть подсказки для этого слова | `Esc` |
| выключить на время / включить | `Ctrl+Alt+P` или значок «А» возле часов |
| настройки, мои слова, загрузка истории | значок «А» возле часов |
| выйти | значок «А» возле часов → «Выход» |

Слово вставляется с пробелом, набранное начало стирается. Если подсказка не нужна,
просто печатайте дальше.

### Окно подсказок

- Цвета берутся из Telegram: программа читает цвет фона поля сообщения (только один
  преобладающий цвет, изображение не сохраняется) и подстраивает окно под дневную,
  ночную или любую другую тему. Если Telegram прочитать не удалось, берётся светлая
  или тёмная тема Windows. В настройках можно выбрать и постоянные цвета.
- Первое слово выделено: его вставляет `Tab`. Номера клавиш не загромождают окно и
  появляются, только пока зажат `Ctrl` (как подсказки `Alt` в Windows). В настройках:
  «всегда» или «никогда».

### Настройки (значок «А» → «Настройки…»)

| Раздел | Что там |
|---|---|
| Подсказки | предпросмотр окна, цвета, номера клавиш, сколько слов показывать, длина слов, следующее слово, узбекская письменность, сдвиг окна |
| Мои слова | поиск по словарю, удаление выбранных слов, очистка всего словаря |
| Загрузить историю | пошаговая инструкция экспорта из Telegram и загрузка |
| Общие | автозапуск с Windows, где лежат данные, памятка |

Все изменения действуют и сохраняются сразу, кнопки «Сохранить» нет.

### Загрузка истории из Telegram

Чтобы подсказки были полезны с первого дня, программа может выучить слова из старых
сообщений (`app/importer.py`):

1. Telegram Desktop → чат → ⋮ → «Экспорт истории чата» (или «Настройки → Продвинутые
   настройки → Экспорт данных из Telegram» для всех чатов). Фото и файлы не нужны,
   формат HTML или JSON.
2. Значок «А» → «Загрузить историю из Telegram…» → выбрать папку экспорта.
3. Если в экспорте не сказано, кто вы (экспорт одного чата), выбрать себя в списке.

Учатся только ваши собственные сообщения; пересланные, чужие, сообщения через ботов,
ссылки, упоминания и код пропускаются. Старые сообщения весят меньше недавних (то же
затухание, что и при наборе). Повторная загрузка того же экспорта не удваивает счётчики:
для каждого чата запоминается номер последнего загруженного сообщения. Загрузку можно
прервать, следующая продолжит с того же места. Скорость: около 50 000 сообщений за 15 секунд.

## Готовая программа (.exe)

`build.bat` собирает один файл `dist\TelegramSuggest.exe` (около 40 МБ): Python и
права администратора на компьютере пользователя не нужны. Файл можно просто отправить.

При первом запуске:

- открывается окно «Подсказки для Telegram» с короткой памяткой клавиш;
- включается автозапуск с Windows (галочка прямо в этом окне, выключается там же, в меню
  значка или в настройках). Автозапуск пишется в `HKCU\...\CurrentVersion\Run` текущего
  пользователя; если файл перенести в другую папку, при следующем запуске путь обновится.

Сборка: тесты → обёртки UI Automation (`comtypes`) → иконка и сведения о версии →
PyInstaller (`TelegramSuggest.spec`) → проверочный запуск собранного файла с отдельной
базой (такой запуск не трогает автозапуск и не показывает приветствие).

## Запуск из исходников

Требуется Python 3.11+ (проект разрабатывается на 3.14) и Windows 10/11.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

| Файл | Что делает |
|---|---|
| `run.bat` | обычный запуск, без окна консоли: появляется значок возле часов |
| `build.bat` | сборка `dist\TelegramSuggest.exe` |
| `TelegramSuggest.pyw` | запуск без консоли (им же пользуется автозапуск и сборка) |
| `run_diag.bat` | запуск с консолью, где видно, что «видит» программа (только для проверки) |
| `scripts\show_overlay.py` | показывает окно подсказок с тестовыми словами: проверка вида и позиции |
| `scripts\try_core.py` | проверка подсказок в консоли, без Telegram и без записи на диск |

Тесты: `.\.venv\Scripts\python.exe -m pytest`

Данные: `%APPDATA%\TelegramSuggest\data.db`. Журнал: `%LOCALAPPDATA%\TelegramSuggest\logs\app.log`
(в журнале только технические события, без набранного текста).

## Как это устроено

```
app/
  main.py          точка входа: связывает потоки и интерфейс
  hook.py          низкоуровневый хук клавиатуры в отдельном потоке
  worker.py        рабочий поток: клавиши -> буфер слова -> подсказки -> вставка
  keymap.py        клавиша -> символ с учётом раскладки окна Telegram (ToUnicodeEx)
  window_watch.py  активно ли окно Telegram
  engine.py        буфер слова: поток символов -> подсказки и обучение
  lexicon.py       словарь в памяти: поиск по префиксу, ранжирование, биграммы
  textutil.py      границы слов, правила «что запоминать», токенизация
  translit.py      транслитерация узбекского кириллица <-> латиница
  store.py         SQLite: слова, биграммы, настройки
  positioning.py   где показать окно подсказок (несколько стратегий)
  overlay.py       окно подсказок, не забирает фокус
  theme.py         цвета окна подсказок: из Telegram или по теме Windows
  inserter.py      вставка слова через SendInput
  tray.py          значок возле часов и его меню
  settings_window.py  окно настроек: подсказки, мои слова, загрузка истории, общие
  welcome.py       приветствие при первом запуске и памятка
  ui_style.py      светлый/тёмный стиль окон программы
  importer.py      чтение экспорта Telegram (HTML/JSON) и обучение на своих сообщениях
  autostart.py     запуск вместе с Windows (HKCU\...\Run)
  ru.py            русские окончания: «1 слово, 2 слова, 5 слов»
  settings.py      настройки
  winapi.py        объявления WinAPI (ctypes)
  paths.py, logsetup.py   пути к данным и журнал
scripts/           проверочные скрипты
tests/             pytest
```

Четыре потока:

| Поток | Что делает |
|---|---|
| хук клавиатуры | решает «наше / не наше», кладёт событие в очередь и сразу возвращается |
| рабочий | символ по раскладке, буфер слова, поиск подсказок, вставка, сохранение в паузах |
| поиск поля | находит поле ввода Telegram через UI Automation (десятки миллисекунд) |
| главный (Qt) | окно подсказок, значок, щелчки мышью |

### Ранжирование

- У каждого слова есть счётчик использований, который затухает со временем
  (по умолчанию вдвое за 30 дней). Недавние слова оказываются выше старых.
- Если слово часто идёт после предыдущего (биграмма), оно получает прибавку:
  после «Салом» первым будет «алейкум».
- Ў/у, Қ/к, Ғ/г, Ҳ/х при поиске считаются одной буквой: «кил» найдёт «қилдим».
- Регистр: имя, написанное с заглавной в середине фразы, запоминается с заглавной.
  Заглавная в начале предложения ничего не доказывает и не учитывается.
- Не запоминаются: числа, ссылки, почта, @имена, #теги, слова короче 2 букв
  и слова из одной повторяющейся буквы.

### Положение окна подсказок

У Telegram Desktop нет системной каретки, и положение каретки он не сообщает.
Зато Telegram 5+ (Qt 6) отдаёт через UI Automation прямоугольник поля ввода.
Поэтому окно ставится над левым краем поля, как строка подсказок на телефоне.
Стратегии пробуются по очереди (`app/positioning.py`):

1. `CaretStrategy`: системная каретка (`GetGUIThreadInfo`). У Telegram её нет, оставлена для совместимости.
2. `UiaStrategy`: поле ввода с фокусом через UI Automation; заодно определяет поля паролей.
3. `WindowStrategy`: запасной вариант по размерам окна Telegram, работает мгновенно.

Сдвиг от автоматической позиции задаётся настройками `overlay_offset_x`, `overlay_offset_y`.

### Вставка слова

Один вызов `SendInput`: отпустить зажатые Ctrl/Shift, Backspace по числу набранных букв,
слово символами Unicode (без буфера обмена), вернуть Ctrl/Shift. Пакет попадает в поток ввода
целиком, физические нажатия не могут вклиниться в середину. Свои события программа помечает
и сама их не обрабатывает.

### Приватность

- Пока активно не окно Telegram, хук не смотрит, какая клавиша нажата
  (кроме Caps Lock: его состояние нужно знать для регистра букв).
- Поля паролей: если Telegram сообщает, что фокус в поле пароля, набор не читается совсем.
- В журнал не попадают клавиши, префиксы, слова и подсказки.
- Цвет темы: не чаще раза в 2 секунды берутся пиксели поля сообщения Telegram, из них
  вычисляется один цвет фона, сами пиксели сразу отбрасываются.
- Загрузка истории: файлы экспорта только читаются; в словарь попадают слова и пары слов,
  тексты сообщений нигде не сохраняются.

## Простота для обычных пользователей

Программа рассчитана на людей, которые не разбираются в компьютерах:

- Запуск двойным щелчком по одному `.exe`, без установки Python и прав администратора (этап 5).
- Никакой консоли и редактирования файлов: всё управление через значок возле часов и окна настроек.
- Весь интерфейс и все сообщения на русском, понятным языком.
- При первом запуске короткое приветствие: что делает программа, какие клавиши, где значок.
- Разумные настройки по умолчанию: работает сразу, ничего настраивать не нужно.
- Понятные сообщения об ошибках с подсказкой, что делать.

## Известные ограничения

- Если Telegram запущен «от имени администратора», а программа нет, Windows не даёт ей
  ни видеть клавиши, ни вставлять текст.
- Программы с перехватом клавиатуры иногда вызывают ложные срабатывания антивирусов.
